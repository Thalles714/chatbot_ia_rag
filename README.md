🤖 Chatbot Inteligente com IA (RAG)

Este projeto é um chatbot inteligente desenvolvido em Python que utiliza IA generativa para responder perguntas com base em dados próprios, simulando um atendimento real de uma churrascaria focada em delivery.

---

## 🚀 Tecnologias utilizadas

- Python
- API da OpenAI
- ChromaDB (banco vetorial)
- RAG (Retrieval-Augmented Generation)

---

## 🧠 Como funciona

O sistema utiliza o conceito de RAG (Retrieval-Augmented Generation):

1. O usuário faz uma pergunta
2. O sistema busca informações relevantes no `data.txt`
3. Esses dados são enviados como contexto para a IA
4. A IA gera uma resposta mais precisa e contextualizada
